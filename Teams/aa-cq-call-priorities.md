# Set up call priorities for call queues

Call priorities in Microsoft Teams allow you to set the order in which calls are routed to agents in a call queue. This is useful for ensuring that high-priority calls are answered first, while lower-priority calls are held in a queue until an agent becomes available.

Before reading this article, make sure you have read [Plan for Teams Auto attendants and Call queues](plan-auto-attendant-call-queue.md).

There are five levels of call priority:

1. **Very High**
1. **High**
1. **Normal** (default setting)
1. **Low**
1. **Very Low**
